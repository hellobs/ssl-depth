### 组员 A（自动化方向）

**主任务：复现技术实验，核第五章的数字**

具体做法：

1. 装环境。用 `D:\zzr\microwm\.venv` 这个现成的 Python 环境，里面 torch 和 opencv 都有。
2. 跑这条命令，看能不能复现出 ImageNet 那一行的结果：

   ```
   cd D:/zzr/ssl-depth
   /d/zzr/microwm/.venv/Scripts/python.exe scripts/diag_backbone.py --backbone imagenet --epochs 15
   ```

   跑完会在 `runs/v2_imagenet/metrics.json` 生成指标。对照论文表里的 val δ1 0.858 和绝对相对误差 0.124。

3. 读懂 `scripts/diag_backbone.py` 的结构：骨干、解码器、损失、评测四部分。论文第三节要讲清楚这些，需要你把把关。
4. 整理"模型在哪里出错"。从 `paper/stimuli/manifest.json` 里挑出预测距离与真值差距大的帧，看画面里是什么内容（玻璃幕墙、远景、弱纹理），归纳成两到三类失效场景，写进论文第五章第三节。

**交付物**：一段 500 字左右的失效模式分析，加复现截图。

### 组员 B（大数据方向）

**主任务：测试数据统计与图表**

具体做法：

1. 等测试数据收上来（我这边会给你一份 CSV，字段是 subject, version, frame, choice, rt_ms）。
2. 算三件事：
   - 每种方案的正确率（choice 与真值比）
   - 每种方案的平均反应时与标准差
   - 每种方案在"模型判断出错"的那些帧上的跟随率（被试选了跟模型一样但跟真值不同的答案）
3. 做两张图：
   - 三方案的正确率与反应时对比，柱状图，带误差棒
   - 三方案的跟随率对比，柱状图
4. 如果样本够，做一个单因素方差分析，报告 p 值。不够就只报描述统计，不要硬上检验。

**交付物**：两张 png 图（300 dpi），加一段结果描述，直接可以贴进论文第七章。

## 几个说明

**关于数据可信度**

论文里的技术指标是初步结果，评测集只有 3 趟飞行、205 帧，波动较大。我在论文里已经写明这一点，组员 A 复现时如果数字有小幅出入是正常的，不用慌，报实际跑出来的数。

**关于测试的局限**

现在的二十帧素材，模型全部判断正确，所以测不出"模型出错时界面会不会误导人"这件事。这是 v1 的局限。等主实验跑完，我会补一批模型判断错误的帧，用同一套协议再测一轮。组员 B 的统计脚本要写成能处理两批数据的。

**关于分工的弹性**

如果谁手头的活儿提前做完，优先帮 C 排版，那是最后卡时间的环节。
