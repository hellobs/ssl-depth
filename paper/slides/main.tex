\begin{frame}{单目深度估计}

\textbf{单目}指只用一只相机。\textbf{深度}是场景点沿光轴到相机平面的距离，即相机坐标系下的 $Z$ 分量。\textbf{深度估计}就是从一张图把每个像素对应的这个量恢复出来。

\vspace{0.2cm}
\begin{itemize}
    \item 单张图在几何上没有唯一解：同一个像点，可能来自近处的小物体，也可能来自远处的大物体
    \item 人靠线索判断：近处纹理粗、远处细；被遮挡的物体在后；车道线宽度这类已知尺寸可以反推；平行线汇聚到消失点
    \item 这些线索都不精确，单目测距天生带误差，而且误差往往有方向
\end{itemize}

\vspace{0.2cm}
\textbf{相对深度}只要求顺序，允许整体缩放。\textbf{米制深度}直接给米数。无人机要判断九米以内有没有障碍，只能要后者。

\vspace{0.1cm}
{\small 标签取\textbf{视差} $1/d$，即深度的倒数。倒过来之后近处差异被放大，而近处正是避障关心的区间。}

\src{Ranftl R, Bochkovskiy A, Koltun V. Towards Robust Monocular Depth Estimation: Mixing Datasets for Zero-shot Cross-dataset Transfer. TPAMI, 2020.}
\end{frame}

\begin{frame}{数据采集与处理}

\begin{itemize}
    \item 平台：Unreal Engine 4 的 AirSim，场景为 CityEnviron 城市峡谷
    \item 采集 422 个航段、75,194 帧；按深度范围 0.5 至 80 米、帧有效率 50\% 清洗，保留 48,767 帧
    \item 真值由渲染引擎直接输出，与图像逐像素对齐，单位是米
    \item 划分按航段切：训练 375 段、验证 14 段、测试 15 段，留出集 3,326 帧
\end{itemize}

\vspace{0.3cm}
按航段切而不是按帧随机切，是因为同一趟相邻帧只隔 0.2 秒。随机切会让测试画面在训练时见过，指标虚高。

\vspace{0.15cm}
40 米以外的远景与大面积天空被剔除，数据在近场偏薄。这一构成会影响后面的误差分布。

\src{Shah S, Dey D, Lovett C, Kapoor A. AirSim: High-Fidelity Visual and Physical Simulation for Autonomous Vehicles. FSR, 2017.}

\begin{frame}{卷积神经网络}

\begin{itemize}
    \item 图像是数值网格，192$\times$108 共六万多个数。全连接层参数比数据还多，必须先压缩连接
    \item 卷积核是一个小窗口，通常 3$\times$3，在整幅图上滑动，权重不变，这叫权值共享
    \item 一个核相当于一个局部模式检测器：竖直边缘、横向边缘、某个方向的纹理
    \item 堆叠之后，浅层响应边缘，深层把边缘组合成角、轮廓、部件
    \item 池化层降分辨率，同时扩大感受野，让后面的核看到更大的原图范围
\end{itemize}

\vspace{0.2cm}
与全连接相比，卷积把参数量压到几千分之一，代价是只擅长局部模式，全局关系要靠堆层数与注意力机制补。

\src{LeCun Y, Bottou L, Bengio Y, Haffner P. Gradient-Based Learning Applied to Document Recognition. Proceedings of the IEEE, 1998.}
\end{frame}

\begin{frame}{残差网络}

{\footnotesize
\begin{itemize}\setlength{\itemsep}{0.5pt}
    \item ResNet18 是卷积网络的一种固定结构：18 个带权重的层，四个阶段，每阶段两个残差块
    \item 每过一阶段分辨率减半、通道加倍；去掉分类头，取 512 通道、4$\times$6 的特征图当表征
    \item 加深不必然更好：二十层之后训练误差反而上升，原因是梯度逐层相乘越传越小，不是过拟合
    \item 残差块把输入直接加到输出上，反向传播有一条不经过卷积的短路，网络只需学差值
\end{itemize}}

\begin{frame}{视觉 Transformer}

{\footnotesize
\begin{itemize}\setlength{\itemsep}{0.5pt}
    \item Transformer 原本处理序列，核心是\textbf{自注意力}：每个位置与所有位置算相关性，再加权求和
    \item 图像没有天然的先后。ViT 把图切成小块，每块拉直成向量，加上位置编码，块与块之间才有区分
    \item 本文的 ViT：576 个块（每块 6$\times$6 像素）、6 层、192 维、3 个头，权重随机初始化
\end{itemize}}

\begin{frame}{变分自编码器}

\begin{itemize}
    \item 编码器把一帧压成低维向量（称为 latent，隐变量），解码器再从它还原这一帧
    \item 变分的意思是编码器输出均值与方差，代表一个高斯分布，从里面采样再解码
    \item 损失有两项：重建误差，以及 KL 散度，后者衡量学到的分布与标准正态差多少
    \item KL 让隐空间连续，相近的点解码出相近的画面
\end{itemize}

\vspace{0.2cm}
2018 年的世界模型用这套结构做视觉端，把每帧压成低维向量，再在向量空间里预测下一帧。

\vspace{0.15cm}
本文取它的编码器。96$\times$96 的输入压成 6$\times$6 个格，每格 256 维，一共 36 个格。它学的是把画面还原出来，不是测距。

\src{Kingma D P, Welling M. Auto-Encoding Variational Bayes. ICLR, 2014.}
\end{frame}

%--------------------------------------------------------------
\begin{frame}{世界模型与联合嵌入预测}

\begin{itemize}
    \item LeCun 的主张：不在像素层面预测未来，而在表征空间预测世界的下一步
    \item JEPA 只用相邻帧，预测下一帧的表征，不还原像素；目标由教师编码器给出，教师只做指数滑动平均，避免表征塌成常数
    \item 编码器是视觉 Transformer：图切成 6$\times$6 的小块，每块变成一个向量（token），共 576 个；自注意力让每个 token 与全部 token 计算相关性，一次看到全图
\end{itemize}

\begin{frame}{两条路径的对照}

{\footnotesize \textbf{四个模型用同一批数据训练。}同样的 375 个训练航段、43,271 帧，同一验证集与测试集；只训练同一个 0.81 M 的解码头（M 指百万参数），同样 15 轮、同一优化器。}

\vspace{0.1cm}
{\footnotesize \textbf{编码器是故意冻住的。}让深度信号回传，四行的差别就不再是表征本身，而变成谁更容易被微调。解冻的对照也跑过：ResNet18 掉到 0.677，VAE 升到 0.562。冻结之后，表里测的是表征里还剩多少可解码的深度。}

\begin{frame}{问题的提出}

\begin{itemize}
    \item 误差在 10 米以内显著恶化，方向一致地读远。使用者从经验里形成的平均印象，恰好覆盖了最危险的区间
    \item 人机交互把这种状态称为信任失准：使用者对系统能力的判断偏离实际能力
    \item 两个方向里，过度信任更危险，因为它的后果是漏判
\end{itemize}

\vspace{0.3cm}
本章要处理两件事：误差分布如何进入界面，人的判断如何回到训练数据。前者是呈现问题，后者是流程问题。

\src{Parasuraman R, Riley V. Humans and Automation: Use, Misuse, Disuse, Abuse. Human Factors, 1997.}
\end{frame}

\begin{itemize}
    \item 每次触发都留下可追溯的判断：可信、有保留、不可信、无法判断
    \item 选后三项时展开结构化理由，记录带时间戳
    \item 判断经溯源、评判、聚合三环，成为下一版模型的训练数据
\end{itemize}

Chen 等提出的 OpenValue 已把这条链路工程化：模型在可配置场景中体验决策后果并生成结构化反思，评审者的判断与理由被链回原始记录，形成可审计的治理材料。

\begin{frame}{结语}

\begin{enumerate}
    \item 表征差异是真实的。固定编码器只换表征，测试集 $\delta_1$ 从 0.467 到 0.875。
    \item 误差集中在近场且方向单一。0 至 10 米 $\delta_1$ 为 0.692，近场系统性读远。
    \item 指标排序与任务排序背离。$\delta_1$ 最高的模型，9 米判据上漏判最多。
\end{enumerate}

\vspace{0.3cm}
\textbf{限制}：无容量对齐的对照，ResNet18 比 JEPA 大近四十倍；数据全部来自仿真，真机迁移未验证；复核闭环只接通，效果未评估。
