# 已废弃的权重

这里的文件**不能用于任何结论**，只作为流程图错误的证据保留。

## jepa_domain_leaky/

2026-11-18 第一次跑域内 JEPA 预训练的产物。

- `jepa.pt` —— 预训练权重，语料 100 个 episode / 17,492 帧对
- `head.pt` —— 用该权重训练的深度头
- `metrics.json` —— 该头在测试集上的指标：δ1 0.830 / AbsRel 0.177

**为什么废弃**：它按 run 名排除测试集（`--skip-runs 1d3aec79,cf2e5d5e`），
但数据划分是 episode 级的，同一个 run 的不同 episode 会落到训练集和测试集两边。
实测 16 个测试 episode 里有 **14 个**进过预训练，验证集的 15 个则**全部**进过。

**危险之处**：它的 δ1 是 0.830，干净版是 0.829 —— 差 0.001，肉眼和表格都看不出异常。
光看数字无法分辨，只能靠路径来防。

可引用的是 `runs/jepa_domain_clean/`（δ1 0.829 / AbsRel 0.163），
语料限定为不含任何验证、测试 episode 的 56 个纯训练 run（见 `runs/pure_train_runs.txt`）。

**教训**：切分预训练语料必须按与评测相同的粒度（episode），不能按上一层容器（run）排除。
